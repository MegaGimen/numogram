# CCRU Numogram · 数密图拓扑流动与能量动力学可视化

> 基于尼克·兰德（Nick Land）与 CCRU（控制论文化研究小组）**数密图（Numogram / 十进制迷宫）** 数学拓扑构建的 **图神经网络（GNN）** 与 **连续 Hopfield 能量网络** 动态演化系统。

---

## 🌌 空间拓扑结构（三层时间系统）

数密图由 10 个区域（Zone 0..9）与 5 对合朔双生对（Syzygies，求和为 9）构成，在二维空间中呈现为经典的三层空间结构：

```
                    [ 3 ] <=========> [ 6 ]
                   Pabbuk            Tchattuk
               ====================================
               ▲       WARP // 扭曲区 [上]        ▲
               │                                  │
     [ 5 ] ─── Gt-15 (虫洞)              (虫洞) Gt-03 ─── [ 2 ]
    Bubbamu                                              Oddubb
       │                                                   │
     [ 4 ] ─── Gt-10 ───┐                  ┌─── Gt-28 ─── [ 7 ]
    Pupana              ▼                  ▼              Puppo
                    [ 1 ] <==============> [ 8 ]
                   Murrumur   Gt-36(虫洞)  Minommo
               ====================================
                   TORQUE // 人类时间回路 [中]
                                │
                                ▼
                            [ 9 ] Katak (Barker's Spiral)
                              │
                            [ 0 ] Utunul (The Abyss)
               ====================================
                     PLEX // 数丛深渊 [下]
```

1. **WARP // 扭曲区 [上层]**：
   - 区域：**Zone 3**（Pabbuk）与 **Zone 6**（Tchattuk）。
   - 性质：合朔对偶 `6::3`，激流引力子自折叠于 3；通过数字根通道 `3 ➔ 6` 与 `6 ➔ 3` 构成两步跃迁。
2. **TORQUE // 人类时间回路 [中层]**：
   - 区域：**Zone 1, 2, 4, 5, 7, 8**。
   - 对偶与激流：
     - 左翼 `5::4` 激流流向 **Zone 1**（汇点 Sink）；
     - 脊柱 `8::1` 激流流向 **Zone 7**（涌点 Surge）；
     - 右翼 `7::2` 激流流向 **Zone 5**（滞点 Hold）；
     - 构成 `5/4 ➔ 1 ➔ 7 ➔ 5` 的闭合扭矩涡流。
   - 倍增时钟：`1 ➔ 2 ➔ 4 ➔ 8 ➔ 7 ➔ 5 ➔ 1`（人类历法时间循环）。
   - 跃迁虫洞：
     - `Zone 2 ➔ Zone 3`（Gt-03，通往 Warp）；
     - `Zone 5 ➔ Zone 6`（Gt-15，通往 Warp）；
     - `Zone 8 ➔ Zone 9`（Gt-36，通往 Plex 深渊）。
3. **PLEX // 数丛深渊 [下层]**：
   - 区域：**Zone 9**（Katak，巴克螺旋）与 **Zone 0**（Utunul，深渊/地心）。
   - 对偶：`9::0`，激流引力子归于 9。

## 🎨 前端温度图（Thermal Diffusion）特性

可视化前端位于 `web/` 目录，通过 `server.py` 服务于 `http://0.0.0.0:8088`：

1. **三维立体渲染**：
   - **底图**：2D 连续热扩散云图（Spatial Thermal Bloom），基于各节点标量激活度动态合成高斯热力场；
   - **粒子流**：激流（Currents）、虫洞（Channels）、倍增（Doubling）边上附带高速光子粒子，流速与密度直接受能流强度驱动；
   - **矢量拓扑**：精确刻画标准对称构型与 CCRU 原版坐标构型。
2. **双动力学模拟引擎**：
   - **GNN 闭环扩散**：多关系邻接图（激流矩阵、通道矩阵、倍增矩阵）上的加权马尔可夫扩散与衰减；
   - **连续 Hopfield 能量弛豫**：合朔互补、激流引力、双阱极化、阈值门控导通的梯度下降极小值搜索。
3. **交互与探测**：
   - 点击任意 Zone 注入正/负热能；
   - 实时监控三大系统（Warp、Torque、Plex）的热力分配；
   - 十区域温度计与虫洞导通指示器（`OPEN` / `LOCKED`）；
   - 支持多套热力色谱（Inferno 熔火、Cyber Neon 赛博荧光、Coolwarm 冷热双极、Solar 日冕）。

## 🚀 启动与使用

### 启动服务
```bash
python server.py 8088
```
访问本地浏览器：`http://localhost:8088`

### 文件说明
- `numogram.py`：数密图图网络建模与多关系邻接矩阵定义；
- `hopfield_numogram.py`：能量型 Hopfield 网络动力学与连续弛豫；
- `explore.py`：数论验证、时间系统周期与代数特征探索；
- `run_hopfield.py`：多初始态模拟与吸引子聚类分析；
- `server.py`：Python HTTP 后端服务与 REST API（端口 8088）；
- `web/`：现代化前端静态资源（`index.html`、`style.css`、`app.js`）。
